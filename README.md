# MAEHR FIT

Persönliche Gesundheits-App im Stil der MAEHR BUSINESS SUITE: **Erholung, Belastung und Schlaf** aus den Messwerten eines
WHOOP-Bands – mit offengelegten Formeln, bei denen jede Zahl bis zur Messung und zur Rechenregel zurückverfolgt werden kann.

- **Daten bleiben auf dem Gerät.** Keine Anmeldung, kein Server, keine Verbindung ins Internet. Health Connect wird nur gelesen.
- **Kein medizinischer Rat.** Die App beschreibt Messwerte und Tendenzen. Sie ist kein Medizinprodukt und stellt keine Diagnosen.
- **Datenquellen:** Health Connect (Android) oder der Datenexport der WHOOP-App (ZIP/CSV).
- **Im Repo nur erfundene Daten** („Musterperson“). Eigene Exporte gehören in `eigene_daten/` (von Git ausgeschlossen).
